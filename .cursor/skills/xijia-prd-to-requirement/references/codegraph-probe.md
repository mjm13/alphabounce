# codegraph 架构探针（Step 1.5）

必须使用 `codegraph-backend` / `codegraph-frontend`（按触达栈）。

## 输出

1. 术语 → 代码实体（类/函数/表/字段/文件）
2. 外键或数据关联链路
3. 共享模块引用者 ≥2 标 ⚠️
4. 可复用接口/函数/模型清单

## 回填落点

- Gate-0 `## 数据流闭环表`（来源/去向证据）
- Gate-1 `## 实现方案`：复用映射、影响面与回归范围

## MCP 不可用

标 `[MCP不可用]`；不得伪造路径；关键未知 → `xijia-spike-probe`。

## 与 A.0.5 的关系

本探针在 **PRD 落盘**时执行，结果写入 Gate-1「实现方案」。  
`/xijia:start` A.0.5 与本节同构，**仅当** `--check-plan` 报缺字段时增量补全，不代替首次写入。
