## 范围与切片

> 背景：依赖 P7（当前星球/坐标/解锁）、P8（Minerals 入账）、P1/P7（单关清关触发进入 lander）。  
> 对照：`lander/Game.hx`、`lander/Hero.hx`、`lander/Mineral.hx`、`lander/House.hx`、`navi/Map.hx::confirmLander`。

### In Scope（本期交付）

- **流程衔接**：打砖块关卡通关/退出 → 进入当前星球 lander 场景 → 结束 lander 回到 `WorldMap`（对齐 `Api.endLander` / `confirmLander` 语义）
- **Hero 控制**：Stand/Run/Jump/Fly 状态（资产 `mcHeroStand/`、`mcHeroRun/`、`mcHeroJump/`、`mcHeroFly/`）
- **Mineral 采集**：地表生成/碰撞拾取，计数并入 P8 `Economy`（非关内硬编码加分）
- **House 交互**：进入/标记房屋（`flMarkHouse` / `flHouseVisited`）；房屋场景与奖励（对照 `lander/House.hx`）
- **星球地表**：按星球 ID 加载 `landerPlan*` / `landerDecor` 布局；区域边界与旅行
- **Sonar/碎片关**：含 Earth 碎片的星球上，指定关卡/地标可触发碎片收集（与 P7 Sonar 规则一致）
- **数据表**：`android/data/lander/planet_surfaces.json`（每星球地表参数、mineral 密度、house 点位）

### Out of Scope

- 世界地图 UI 本体 → P9（本需求提供 lander↔map 状态回调）
- 商店/装备购买 UI → P9 + P8/P8b
- 打砖块关卡生成 → P7
- 网络/账号 API → 无（单机化 `Api.*` 为本地事件）

# Gate-1 方案与验收

## 验收标准

- [ ] **AC-1**：清关后自动进入 lander，结束 lander 回到世界地图，状态不丢失
  - **反例（本 AC 排除）**：关内直接结算 mineral，无 lander 场景
- [ ] **AC-2**：Hero 可在地表移动/跳跃/飞行，Mineral 拾取计入 P8 经济
  - **反例（本 AC 排除）**：mineral 仅 HUD 假数字
- [ ] **AC-3**：House 可进入并标记；`flHouseVisited` 等价状态可持久化（P11 接口）
  - **反例（本 AC 排除）**：House 纯装饰不可交互
- [ ] **AC-4**：含 Earth 碎片的星球：Sonar/碎片关逻辑与 P7 一致（打特定关/地标得碎片）
  - **反例（本 AC 排除）**：碎片关与 P7 规则矛盾
- [ ] **AC-5**：对照 `lander/Game.hx`：同星球 seed 下地表 mineral/house 布局可复现
  - **反例（本 AC 排除）**：每次随机不一致
