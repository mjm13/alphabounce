## 实现方案

> 环境现状（2026-08-18 探针）：`godot` 未安装、`ANDROID_HOME`/`ANDROID_SDK_ROOT` 未配置、JDK 未配置、无 Android SDK。本方案含 **Spike-0 前置** 验证下载能力，若环境无法下载则按下方降级路径执行（仅 Godot 工程 + 安卓导出预设配置，APK 构建记入 P12 并标注 blocker）。

- 架构 / 关键改动：以 `android/` 为 Godot 工程根；通过 Godot 官方 standard 构建（GDScript）创建工程；安卓导出依赖 Godot 内置 Android 导出器 + 外部 Android SDK/JDK/debug keystore；导出产物 `android/build/Alphabounce-debug.apk` 经 `adb` 安装验证。
- 复用映射 / 代码落点：`android/`（工程根）、`android/project.godot`、`android/export_presets.cfg`、`android/build/`、`AGENTS.md`（命令回填）。
- 影响面与回归范围：仅工程基座，不触达任何玩法代码；回归点=`godot --headless --path android --quit` 与 `adb install`。

### Spike-0（前置探针，阻塞后续）

- **目标**：确认本环境可获取 Godot 4 + Android SDK/JDK，避免后续切片空转。
- **最小实验**：
  1. 探测网络：`curl -I https://github.com/godotengine/godot/releases` 可达；`curl -I https://dl.google.com/android/repository/commandlinetools-...` 可达。
  2. 磁盘：`df` 确认 `E:/Project/Self` 所在盘 ≥ 5GB 空闲。
  3. 尝试下载 Godot 4.x standard 二进制到 `tools/godot/`（仅验证可下载，不跑工程）。
- **预期证据**：上述 URL 返回 200；磁盘充足；Godot 二进制可下载。
- **退出标准**：`continue`（全部可达）→ 执行切片 1–6；`partial`（Godot 可达但 SDK/JDK 不可达）→ 执行切片 1–2 + 切片 4 的 `export_presets.cfg` 手写配置（不实际导出），APK 构建降级至 P12；`reject`（Godot 也不可达）→ 仅产出目录约定文档，工程创建延后并标注 blocker。

### 切片拆解

1. **[AC-1, AC-4] 获取 Godot 4 二进制 + 创建工程**
   - Files: `tools/godot/godot.exe`（或固定路径）、`android/project.godot`、`android/scenes/Main.tscn`、`android/scripts/main.gd`
   - Steps: 下载 Godot 4.x standard → 固定路径并加入 PATH（或记于 AGENTS）；`godot --headless --quit` 验证二进制可用；创建 `project.godot`（`config_version=5`、应用名 `Alphabounce`、配置主场景）；创建 `Main.tscn`（Node2D 根 + ColorRect 背景 + Label "Alphabounce"）+ `main.gd`（`_ready()` 打印启动日志）；`godot --headless --path android --quit` 验证工程可解析。
   - Done: `godot --headless --path android --quit` 退出码 0，且 `android/` 含 `project.godot` 与 `Main.tscn`。

2. **[AC-2] 安装 Android 工具链（JDK + SDK）**
   - Files: 本地环境（非仓库内，路径记于 `AGENTS.md`）；`android/export_presets.cfg` 本切片先建空占位。
   - Steps: 安装 JDK 17（记 `JAVA_HOME`）；下载 Android command-line tools；`sdkmanager` 安装 `platform-tools`、`build-tools;34.0.0`、`platforms;android-34`；`sdkmanager --licenses` 接受全部；记 `ANDROID_HOME`/`ANDROID_SDK_ROOT`。
   - Done: `sdkmanager --list` 含上述组件；`java -version` 输出 17；licenses 已接受。

3. **[AC-2] 生成 debug keystore**
   - Files: `android/debug.keystore`（加入 `.gitignore`，勿入库）
   - Steps: `keytool -genkey -v -keystore android/debug.keystore -alias alphabounce -keyalg RSA -keysize 2048 -validity 10000`（密码记于 `AGENTS.md` 本地段，勿提交明文）。
   - Done: `keytool -list -keystore android/debug.keystore` 成功列出 `alphabounce` 别名。

4. **[AC-2, AC-3] 配置安卓导出预设并导出 APK**
   - Files: `android/export_presets.cfg`
   - Steps: 用 Godot 编辑器或 headless 配置 Android 预设（名称 `Android`、平台 `Android`），填入 `android_sdk_path`、`debug_keystore`、`keystore_user=alphabounce`、`keystore_password`；或手写 `export_presets.cfg`（含 `[preset.0]` 段与 `android/` 相关字段）；导出 `godot --headless --export-release "Android" android/build/Alphabounce-debug.apk`。
   - Done: `android/build/Alphabounce-debug.apk` 存在且为有效 APK。

5. **[AC-3] adb 安装与运行验证**
   - Files: 无（验证动作）
   - Steps: `adb devices` 确认设备/模拟器在线；`adb install -r android/build/Alphabounce-debug.apk`；`adb shell am start -n org.godotengine.alphabounce/org.godotengine.godot.GodotApp`（Godot 默认包名 `org.godotengine.alphabounce`，可在 `project.godot` 配置）；`adb logcat` 确认无 fatal。
   - Done: 应用安装并打开显示主场景（首屏无闪退，logcat 无 fatal）。

6. **[AC-5] 回填 AGENTS.md 命令**
   - Files: `AGENTS.md`
   - Steps: 在 `AGENTS.md` 的 Build and test commands / Testing instructions 写入：启动编辑器 `godot --path android`；工程校验 `godot --headless --path android --quit`；安卓导出 `godot --headless --export-release "Android" android/build/Alphabounce-debug.apk`；安装 `adb install -r android/build/Alphabounce-debug.apk`；并补充 `ANDROID_HOME`/`JAVA_HOME`/`keystore` 路径说明（本地，勿提交明文密码）。
   - Done: `AGENTS.md` 无待补充占位，命令与上一致。

- **回归验证点**（一条可复跑命令组合）：
  - `godot --headless --path android --quit`（工程校验，exit 0）
