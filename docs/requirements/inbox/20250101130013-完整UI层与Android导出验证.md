## 验收标准

- [ ] **AC-1**：主菜单检测到存档时显示"继续游戏"按钮，无存档时隐藏该按钮
  - **反例（本 AC 排除）**：有存档但按钮不显示，或无存档但按钮显示
- [ ] **AC-2**：点击"继续游戏"按钮正确加载 PlayerData.max_level_unlocked 对应关卡
  - **反例（本 AC 排除）**：加载错误的关卡或报错
- [ ] **AC-3**：Game Over 画面"再来一次"按钮重新加载当前关卡（不递增 max_level_unlocked）
  - **反例（本 AC 排除）**：跳转到主菜单或加载错误关卡
- [ ] **AC-4**：Level Clear 画面"下一关"按钮正确加载 level_index + 1 的关卡
  - **反例（本 AC 排除）**：加载相同关卡或越界崩溃

- [ ] **AC-5**：`godot --path game --export-debug "Android"` 成功生成 APK 文件
  - **反例（本 AC 排除）**：导出命令失败或 APK 文件不存在
- [ ] **AC-6**：APK 安装到 Android 设备后可正常运行，触摸控制响应正常
  - **反例（本 AC 排除）**：应用崩溃或触摸无响应
- [ ] **AC-7**：在 Android 设备上完整执行 Main Menu → 开始游戏 → 完成一关 → Game Over → 返回主菜单 流程无报错
  - **反例（本 AC 排除）**：流程中断或报错
