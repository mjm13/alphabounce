# 20250101130007-敌人系统

# Gate-0 澄清与范围

## 原始诉求（verbatim，禁止改写）

> 实现敌人系统：敌人基类、3 种敌人子类（Dragon/Drone/Generator）、敌人管理、敌人碰撞伤害。

## 歧义登记

歧义登记: none（已逐句复核，触达面：敌人系统；确认人:Agnes；日期:2025-01-01）

## 业务目标

增加游戏挑战性和趣味性，敌人在关卡中出现，与球体/玩家交互，被消灭后给予奖励。

## 用例 / 用户故事

1. 作为玩家，我能看到敌人在关卡中出现并按其行为模式移动
2. 作为玩家，球体碰撞敌人时敌人受损，生命归零时消灭并得分
3. 作为玩家，敌人碰撞玩家时玩家失去生命

## 范围与切片

> 背景：glossary.md 定义了 11 种敌人类型；架构文档提到 Enemy 基类和 Molecule 子类。首期实现 3 种。
> In Scope 只写能力边界。

### In Scope（本期交付）

- BaseEnemy.gd：敌人基类（health, speed, state machine, collision with ball）
- Dragon.gd：龙形敌人，定时发射火焰 projectile
- Drone.gd：无人机敌人，巡逻路径移动
- Generator.gd：生成器敌人，定时生成小怪（Minion）
- EnemyManager.gd（Autoload）：敌人生命周期管理（生成、移除、状态同步）
- 敌人碰撞：球体击中敌人造成伤害，敌人碰撞玩家扣生命
- 敌人死亡掉落：消灭敌人后掉落星星或道具

### Out of Scope

- 不做全部 11 种敌人（原因：首期 3 种验证模式；重开触发：后续 PRD）
- 不做敌人 AI 难度曲线（原因：首期固定行为；重开触发：平衡性需求）
- 不做敌人波次系统（原因：首期关卡固定敌人配置；重开触发：R02 关卡数据扩展）
- 不做 Boss 战（原因：独立大需求；重开触发：Boss 需求 PRD）

### 待确认问题与延期项（Open Questions & Deferred）

**Must-Confirm**

- OQ-001：敌人碰撞层 → 结论：layer=8(enemy), mask=5(ball+boundary)
- OQ-002：敌人伤害方式 → 结论：球体碰撞造成 1 点伤害（与方块相同），Dragon 火焰造成 3 点

**Deferred**

- DEF-001：更多敌人类型（Quasar/Storm/UltraViolet 等）→ 后续版本
- DEF-002：敌人 AI 行为树（首期用简单状态机）→ 后续版本

## 验收标准

- [ ] **AC-1**：BaseEnemy.gd 可实例化，具有 health/speed/state 属性，支持 hit(damage) 方法
  - **反例（本 AC 排除）**：无法创建敌人实例或 hit() 不生效
- [ ] **AC-2**：Drone.gd 沿预设巡逻点移动，到达点后转向下一点
  - **反例（本 AC 排除）**：Drone 不移动或方向错误
- [ ] **AC-3**：Dragon.gd 每 2 秒发射一个火焰 projectile，火焰沿方向直线移动
  - **反例（本 AC 排除）**：火焰不生成或方向固定
- [ ] **AC-4**：EnemyManager 可从关卡数据加载敌人并在 World 中正确实例化
  - **反例（本 AC 排除）**：敌人数量为 0
- [ ] **AC-5**：球体碰撞敌人时敌人扣血，生命归零时消灭并掉落星星
  - **反例（本 AC 排除）**：球穿过敌人无反应
- [ ] **AC-6**：火焰碰撞玩家时玩家失去 1 生命，lives <= 0 时触发 Game Over
  - **反例（本 AC 排除）**：玩家不受伤害或 Game Over 不触发
