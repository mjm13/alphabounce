## 范围与切片

> 背景：依赖 P1 单球物理；扩展为多类型 + Multiball 多球。
> In Scope 只写能力边界；可执行验收见 Gate-1 `## 验收标准`。

### In Scope（本期交付）

- 球类型数据：**9 种**（`Cs.hx`：STANDARD/FIRE/ICE/DRUNK/KAMIKAZE/YOYO/HALO/SHADE/VOLT）；同屏上限 **18**（`MAX_BALL`）
- **7 种挡板/船体类型**（`PAD_STANDARD/GLUE/TIME/LASER/GENERATOR/AIMANT/SHAKE`）作为装备接入 P8b loadout
- Multiball：按增益生成额外球，左右分布；球清零回收
- 全部球丢失 → 关卡失败（与 P1 命数联动）
- 多球碰撞去抖与优先级处理

### Out of Scope

- 增益触发 Multiball 的逻辑本体 → P4（本需求提供"生成/回收球"接口）
- 挡板/砖块物理改动 → P1/P2
- 球类型**飞行粒子**（火/冰/电/醉：`genSparks`/`genIceShards`/`mcBolt`）→ **P10**（`20260818214310-AB-P10音频与表现力.md` §球体粒子）
- 关卡 **SAUVETAGE** 落底保护（`flSafe`/`levelTimer`）→ **P3c**（`20260820150300-AB-P3c关卡SAUVETAGE首球保护.md`）

  - **反例（本 AC 排除）**：多球重叠/不回收
- [ ] **AC-4**：所有球丢失触发关卡失败
  - **反例（本 AC 排除）**：空球列表仍不判负
- [ ] **AC-5**：多球碰撞去抖，无穿透/卡死
  - **反例（本 AC 排除）**：多球互相穿透抖动

### 九种球行为（对齐 `el/Ball.hx`）

| 球 | 原作作用 | 真机目测要点 |
|---|---|---|
| 标准 | 1 伤害，正常反弹 | 基准 |
| 火 | 伤害 +1 | 打高耐久砖更快 |
| 冰 | **冻结砖块**（不直接扣血） | 砖变蓝冰层 |
| 醉 | 轨迹随机抖动 | 球路发飘 |
| 神风 | 追踪可破软砖 | 往砖块拐弯 |
| YoYo | 越往下越快（最高约 4×） | 下方速度明显变快 |
| 光环 | 接板后**幽灵态**穿砖无伤，下落时恢复 | 接板后半透明，再落回时变实 |
| 影 | **不可接板**；碰左右墙消失 | 碰挡板/侧墙即没 |
| 电 | 主目标仅闪烁；**链式电击**周围砖 | 一颗砖周围多砖同时扣血 |

左下角 diag 面板固定显示当前 `ball=` / `pad=` 与操作提示行 `--- P3 DIAG: tap SCORE/LIVES/ver | PC B/P/M ---`。
