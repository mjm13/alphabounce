# Gate-1 方案与验收

## 验收标准

- [ ] **AC-1**：关键动作（击碎/反弹/增益/失败）有音效
  - **反例（本 AC 排除）**：静默无反馈
- [ ] **AC-2**：背景音乐可播放与静音
  - **反例（本 AC 排除）**：无法静音
- [ ] **AC-3**：粒子/反馈到位且不卡顿（对象池）
  - **反例（本 AC 排除）**：大量粒子掉帧
- [ ] **AC-4**：**9 种球**中至少火/冰/电/醉在飞行时有可见持续粒子（对齐 `Ball.hx`）；P2 击碎 `partSpark` 不回归破坏
  - **反例（本 AC 排除）**：球仅染色无拖尾/火花/电光

## 实现方案

- 复用映射 / 代码落点：`android/systems/AudioBus.gd`、`android/systems/ParticlePool.gd`（或 `BallFx.gd` 挂 `Ball.gd`）、`android/data/audio/`
- 资产：`partSpark/`、`partIceShard/`、`partBubble/`（待确认）；`mcBolt/` **当前缺失**（OQ-003）
- 切片拆解：

| 切片 | 覆盖 AC | 代码落点 | 验证命令 |
|---|---|---|---|
| 音效总线 | AC-1, AC-2 | `AudioBus.gd` | 手动 |
| 粒子池 | AC-3 | `ParticlePool.gd` | 压力测试 |
| juice 反馈 | AC-3 | `FX` 节点 | 手动 |
| **球体粒子** | **AC-4** | `Ball.gd` 或 `BallFx.gd` | 真机 diag 换球型目测 |

- 回归验证点：
  - Godot 运行表现力测试，验证音效/音乐/粒子与帧率
  - 真机：P3 diag 点 SCORE 切换火/冰/电/醉，可见粒子；`blocks_test.tscn` 仍绿

## 真机验收（diag）

- 依赖 P3 diag（点 SCORE 换球型）
- **火球**：橙色火花拖尾；**冰球**：冰屑；**电球**：闪电/火花（或 OQ-003 占位方案）；**醉球**：气泡
