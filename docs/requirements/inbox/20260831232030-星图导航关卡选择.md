## 验收标准

- [ ] **AC-1**：GIVEN 新建 StarMap WHEN 读取 THEN 含 24 星区、`current_zone==SOUPALINE`、`visited` 含 SOUPALINE。
  - **反例（本 AC 排除）**：星区数量≠24、或 `current_zone` 非 SOUPALINE、或 `visited` 不含起点。
- [ ] **AC-2**：GIVEN 虫洞数据 WHEN 读取 `wormhole_endpoints()` THEN 返回 5 对端点（来自 ZoneInfo.holes）。
  - **反例（本 AC 排除）**：虫洞对数量≠5、或端点坐标非 ZoneInfo.holes 内容。
- [ ] **AC-3**：GIVEN 可选星区 WHEN 调用 `selectable_zones()` THEN 返回 24（v0.3.0 MVP 全可选）。
  - **反例（本 AC 排除）**：返回数量≠24、或仅返回已访问星区（门禁模式属 Deferred，不在本 AC 范围）。
- [ ] **AC-4**：GIVEN 进入某星区 WHEN 调用 `enter_zone(zid)` THEN `current_zone` 更新、`visited` 记录、发出 `zone_selected(zid)` 信号。
  - **反例（本 AC 排除）**：进入后 `current_zone` 未变、或 `visited` 未记录、或 `zone_selected` 未发出。
- [ ] **AC-5**：GIVEN 银河坐标 WHEN 调 `get_zone_screen_pos` THEN 不同星区投影到视口内不同屏幕位置（EARTH 与 SOUPALINE 区分）。
  - **反例（本 AC 排除）**：两星区投影到同一屏幕点、或投影落在视口外（负坐标/超界）。
- [ ] **AC-6**：GIVEN `reachable_zones(engine)` WHEN 从起点星区 BFS THEN 返回 Array 且含起点星区（忠实移植原版 reach）。
  - **反例（本 AC 排除）**：返回非 Array、或空集合（起点星区自身方块必在可达集合内）。
- [ ] **AC-7**：GIVEN 星图场景 WHEN 加载 `star_map.tscn` THEN 非 null 且无脚本错误。
  - **反例（本 AC 排除）**：场景加载为 null、或加载时抛出 SCRIPT ERROR/Parse Error。
