## 范围与切片

- **In Scope**：移植原版 `ZoneInfo` 全部 24 星区数据（name/pos[x,y,radius]/col/pal）+ 小行星带常量（ASTEROBELT_CX/CY/RAY）+ 5 个虫洞（holes），并实现几何辅助 `get_planet / get_squares / is_wormhole / get_box / is_in_circle`，数值与原版逐字对齐。本切片仅为 BL-01 的数据基座，不实现导航与程序化生成。

# Gate-1 方案与验收

## 页面布局预览

## 验收标准

- [ ] **AC-1**：GIVEN `ZoneInfo.get_list()` WHEN 读取 THEN 含 24 星区，每区含 name(String)/pos(长度3, radius>=0)/col/pal(非空)。
  - **反例（本 AC 排除）**：星区数量≠24、或字段缺失/类型错误（如 ASTEROBELT 半径 0 被错误拒绝）。
- [ ] **AC-2**：GIVEN 常量与虫洞数据 WHEN 读取 THEN `ASTEROBELT==13`、`ASTEROBELT_CX==27/CY==6/RAY==110`，`get_holes()` 返回 5 个虫洞对。
- [ ] **AC-3**：GIVEN 已知坐标 WHEN 调用 `get_planet` THEN `get_planet(-7,1)==SOUPALINE`、`get_planet(8000,8100)==EARTH`、远空坐标 `get_planet(1000,1000)==-1`。
- [ ] **AC-4**：GIVEN `get_squares(SOUPALINE)` WHEN 半径为 2 THEN 返回 16 格（全包围盒覆盖）且每格满足 `is_in_circle`。
- [ ] **AC-5**：GIVEN 虫洞坐标 WHEN 调用 `is_wormhole` THEN `is_wormhole(-9,-7)==true`、`is_wormhole(0,0)==false`。
