# Gate-1 方案与验收

## 页面布局预览

## 验收标准

- [ ] **AC-1**：GIVEN 球体以高速（单帧位移 > 安全步长，如 speed=1200 时 ~20px/帧）朝向厚度 12px 的墙 WHEN 单帧物理步进 THEN 球体被墙反弹、最终位置停留在墙内侧（不越过墙中线），即不发生穿墙。
  - **反例（本 AC 排除）**：高速下单步 `move_and_slide` 越过薄墙、球出现在墙另一侧。
- [ ] **AC-2**：GIVEN 常态速度（speed=300，单帧 ~5px < 安全步长）WHEN 物理步进 THEN 行为与无 CCD 完全一致（步数=1，反弹法向、速率、弹道不变），即 R17 匀速对等零回归。
  - **反例（本 AC 排除）**：引入 CCD 后常态弹道偏移、速率衰减或抖动。
- [ ] **AC-3**：GIVEN 高速球体命中砖块（group=blocks）WHEN 子步进中发生碰撞 THEN 仍触发碰撞体 `hit(1)` 与 `block_hit` 信号（砖块命中不遗漏）。
  - **反例（本 AC 排除）**：因子步进拆分导致砖块命中丢失。

## 实现方案

- 架构 / 关键改动：在 `ball.gd._physics_process` 将单次 `move_and_slide` 改为按 `MAX_STEP`（安全步长，默认 8px）拆分的子步进循环；每步设置临时 velocity 使本步位移 = min(MAX_STEP, 剩余位移)，调用 `move_and_slide`，检测 `get_last_slide_collision`，命中则 `velocity = velocity.bounce(normal) * RESTITUTION` 并处理砖块 hit（沿用现有逻辑）；循环结束将 velocity 归一到原速率以保持匀速。
- 复用映射 / 代码落点：

  | 已有模块/服务 | 可复用接口/函数/表 | 关系类型 | 精确坐标 |
  |---|---|---|---|
  | `ball.gd` | `_physics_process` / `move_and_slide` / `get_last_slide_collision` / `velocity.bounce` | 扩展（子步进） | `game/scripts/entities/ball.gd` |

- 切片拆解：
  1. [AC-1/AC-2/AC-3] `ball.gd` 引入 `MAX_STEP` 常量与子步进循环，砖块命中逻辑原样保留于每步。
- 回归验证点：`tools/godot_std/Godot_v4.7.1-stable_win64_console.exe --headless --path game tests/test_ball_ccd.tscn`
