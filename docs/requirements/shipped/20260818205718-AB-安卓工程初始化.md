> 环境现状（2026-08-18 探针）：`godot` 未安装、`ANDROID_HOME`/`ANDROID_SDK_ROOT` 未配置、JDK 未配置、无 Android SDK。本方案含 **Spike-0 前置** 验证下载能力，若环境无法下载则按下方降级路径执行（仅 Godot 工程 + 安卓导出预设配置，APK 构建记入 P12 并标注 blocker）。

- 架构 / 关键改动：以 `android/` 为 Godot 工程根；通过 Godot 官方 standard 构建（GDScript）创建工程；安卓导出依赖 Godot 内置 Android 导出器 + 外部 Android SDK/JDK/debug keystore；导出产物 `android/build/Alphabounce-debug.apk` 经 `adb` 安装验证。

- 影响面与回归范围：仅工程基座，不触达任何玩法代码；回归点=`godot --headless --path android --quit` 与 `adb install`。

### Spike-0（前置探针，阻塞后续）

- **目标**：确认本环境可获取 Godot 4 + Android SDK/JDK，避免后续切片空转。
- **最小实验**：
  1. 探测网络：`curl -I https://github.com/godotengine/godot/releases` 可达；`curl -I https://dl.google.com/android/repository/commandlinetools-...` 可达。
  2. 磁盘：`df` 确认 `E:/Project/Self` 所在盘 ≥ 5GB 空闲。
  3. 尝试下载 Godot 4.x standard 二进制到 `tools/godot/`（仅验证可下载，不跑工程）。
- **预期证据**：上述 URL 返回 200；磁盘充足；Godot 二进制可下载。
- **退出标准**：`continue`（全部可达）→ 执行切片 1–6；`partial`（Godot 可达但 SDK/JDK 不可达）→ 执行切片 1–2 + 切片 4 的 `export_presets.cfg` 手写配置（不实际导出），APK 构建降级至 P12；`reject`（Godot 也不可达）→ 仅产出目录约定文档，工程创建延后并标注 blocker。
