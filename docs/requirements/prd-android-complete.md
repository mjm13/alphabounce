## 对等基线原则（Parity Baseline）

本 PRD 所有验收以**「全部实现即等于原版」**为唯一标准，依据原版源码事实（见 `code-explorer` 提取的特征集）定义，禁止任何降级式 Out of Scope：

1. **画面对等**：所有精灵/音频须从原版资源迁移（见 R15），真机视觉比对无缺失。
2. **内容对等**：关卡/任务/商店/存档/敌人数据须从原版搬运（见 R16），数值与行为一致。
3. **物理对等**：球体弹跳手感对齐原版（见 R17 + ADR-001），使用 `CharacterBody2D.move_and_slide()`。
4. **操作对等**：触摸控制映射对齐原版输入动作（见 R08/R09/R18）。
5. **任务对等**：原版全部任务/奖励/商店兑换覆盖（见 R05/R06/R16）。

> **关于「Boss」的事实澄清**：原版**无独立 Boss 实体**。所谓 Boss 是 `Block.GUARDIAN` 特殊方块（出现在 CILORILE、KHORLAN 等星球，须被导弹击杀，见 `Pad.hx:607`、`Level.hx:777,840`）。本基线将 GUARDIAN 作为「Boss 等价威胁」纳入敌人系统（R08），不臆造原版不存在的 Boss 战。

## 关键决策（ADR 摘要）

- **ADR-001（强化）**：物理系统**必须**使用 Godot 内置 `CharacterBody2D.move_and_slide()`，严禁手动 `position += velocity * delta`（当前 `ball.gd` 违规，须 R03/R17 修正）。这是物理手感对齐原版的硬前提。
- **ADR-002**：关卡数据采用 JSON 配置表，字段须对齐原版 `Level.hx` 数据结构（见 R16）。
- **ADR-003**：玩家存档使用 Godot `UserDirectory` + JSON，字段须对齐原版存档（见 R16）。
- **ADR-004**：音频使用 Godot `AudioStreamPlayer`，音效/BGM 分离，资源来自原版迁移（见 R15）。
- **ADR-005（新增）**：所有美术/音频资源从原版 `frontend/src/static/images/`、`sounds/` 迁移，保持原命名/序列帧结构，禁止重绘替代（除非原资源缺失，须标注）。

4. **物理对等**：球弹跳角度/速度曲线与原版相近，无穿墙/卡死（R17 证据）。
