# 术语表（Glossary）

## 游戏术语

| 术语 | 定义 |
|------|------|
| **Ball** | 玩家发射的球体，用于消除方块 |
| **Block** | 关卡中的方块，需要被消除 |
| **Pad** | 发射台，玩家控制球体发射 |
| **Missile** | 特殊攻击武器，有多种类型 |
| **Mine** | 可收集的资源矿物 |
| **Zone** | 星球区域，共24个 |
| **Mission** | 任务，共47个 |

## DDD 术语

- **Aggregate**: 聚合，领域模型的核心单元
- **Bounded Context**: 有界上下文，领域模型的边界
- **Invariant**: 不变量，必须始终满足的条件
- **Ubiquitous Language**: 通用语言，团队成员共享的词汇

## 缩写

- **AC**: Acceptance Criterion (验收标准)
- **ADR**: Architecture Decision Record (架构决策记录)
- **API**: Application Programming Interface
- **CCD**: Circle Collision Detection (圆形碰撞检测)
- **TDD**: Test-Driven Development (测试驱动开发)
- **GDScript**: Godot 的脚本语言
