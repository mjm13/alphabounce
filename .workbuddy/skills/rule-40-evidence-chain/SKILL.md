# 目标

避免按名称猜结论。输出方案、影响范围、根因前必须形成最小证据闭环。

# 最小证据闭环

- 入口：页面/菜单/命令/API 调用方
- 契约：路径、关键参数、返回语义
- 执行点：后端函数/服务/任务
- 数据落点：表/状态字段/持久化资源

# 约束

1. 未闭环时标记 `[待确认]`，不写成确定结论。
2. 用户补充遗漏入口或角色时，回到取证步骤重建证据链。
3. Bug 场景须给出：复现路径、实际结果、期望结果、证据链断点。
